# Third-party sources

- `VoCoT-main/` contains a locally modified copy of **VoCoT: Unleashing Visually Grounded Multi-Step Reasoning in Large Multi-Modal Models**, by Zejun Li, Ruipu Luo, Jiwen Zhang, Minghui Qiu, and Zhongyu Wei. The retained upstream README identifies `https://github.com/RupertLuo/VoCoT` and paper `2405.16919` as its sources. The exact upstream revision and full local modification history are not available in this workspace.
- `VoCoT-main/requirements.txt` was copied from the workspace's `VOCOT/requirements.txt` to preserve the legacy environment specification used by the retained README and build script.
- Forest-of-Thought is an inspiration/reference project. Its locally downloaded README identifies **Forest-of-Thought: Scaling Test-Time Compute for Enhancing LLM Reasoning**, paper `2412.09078`. Duplicate downloaded FoT/ToT directories and datasets are excluded from this source distribution.

Original author attribution is retained. No repository-wide license grant is added by this packaging step. Consult the original projects and model/data providers for applicable terms before redistribution or reuse.
